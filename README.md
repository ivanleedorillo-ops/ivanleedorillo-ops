## How I build

- **AI drafts, tests decide.** I plan and generate code with AI tools, then review it and keep it only when the tests pass. In HorizonDownload and HorizonBias, tests use mocked services and never call real APIs.
- **Security from the start.** Input validation, rate limits, Content Security Policy, and secrets kept out of Git.
- **Clear limits.** I write down what an app does not do: HorizonBias states plainly that it gives no trade advice, and HorizonDownload has a responsible-use policy.
